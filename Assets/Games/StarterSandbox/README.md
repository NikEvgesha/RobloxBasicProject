# Starter Sandbox

This game folder contains the imported starter scenes from the original Unity Basic Project.

Scenes:

```text
Assets/Games/StarterSandbox/Scenes/Loading.unity
Assets/Games/StarterSandbox/Scenes/Evgesha.unity
```

Keep new sandbox-specific content inside this folder. Promote reusable mechanics to `Assets/GameKit` only after they are decoupled from this game.
